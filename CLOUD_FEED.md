# Independent cloud VLESS subscription

The existing `verified/live-vless.txt` is written by **GWZHUB Publisher**, outside this
GitHub Actions workflow. Its published `Количество: 0` is not repaired by this service.

An independent feed will be published on the `main` branch:

`https://raw.githubusercontent.com/gwz-tools/config-hub/main/cloud-vless.txt`

It will exist **only after a successful cloud workflow run**. Do not configure routers
with that URL before verifying that it contains at least three `vless://` entries.

## How it works

- Reuses `data/gwzhub_candidates.txt` generated by the existing main collector.
- Tests public VLESS endpoints by starting a temporary sing-box HTTP proxy per candidate.
- All HTTPS checks are sent **through that VLESS tunnel**: an initial Google 204 endpoint,
  then Gemini, Instagram, Facebook (Meta), and YouTube.
- A candidate passes only if the control URL responds successfully and at least two of
  four service URLs return HTTP 2xx/3xx. HTTP 401/403/429 is not counted as an
  accessible service. A success from a GitHub runner **does not guarantee access in
  Russia or on a particular ISP**.
- Only publishes if at least three nodes pass. Otherwise retains an existing non-empty
  `cloud-vless.txt`; if none exists the workflow fails without publishing a zero list.
- No private VLESS subscription URLs or authentication tokens should be committed here.
  Configure any private source later with encrypted GitHub Actions secrets.

## Publication and failover

Scheduled at minute 17 every six hours UTC (after the existing 6-hour collector).
Metadata: `data/cloud-status.json`, with counts only. Test all four services, but
do not overstate the result as full website functionality or video playback.

The independent feed is a GitHub Raw URL and may itself use non-domestic infrastructure.
This **reduces upstream requests** from the router but does not bypass ISP charging for
foreign-IP VPN traffic.

A Dropbox / Yandex Disk mirror must be configured separately with credentials and
write permissions; the public mirror must never disclose an API key.

## The original GWZHUB publisher

An additional guard must be installed **on GWZHUB itself** before it uploads to the
`verified` branch. The on-hub publisher is not part of this repository. Reject empty
or malformed output before the API upload, preserve a last-good VLESS snapshot, and
do not advertise the feed as fresh when the last good version is stale.

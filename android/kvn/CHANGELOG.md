# КВН — история версий

## 0.1.2-test — оформление и готовность к GitHub Actions
- Красно-белая светлая тема; широкий фирменный баннер вместо квадратного изображения.
- Android adaptive icon с прозрачной эмблемой и отдельным фоном; прозрачные PNG для старых систем.
- Отдельные счётчики DIRECT/PROXY/BLOCK; явная надпись, что правила ещё не влияют на трафик.
- Сохранены работающие обновления правил, кеш, SHA-256, восстановление старой версии и тесты.
- Добавлена автоматическая сборка APK и тестов GitHub Actions (после переноса исходников).
- VPN-движка и VpnService пока нет: эта версия не защищает соединения.

## 0.1.1-test — первая проверенная сборка
- На JDK 17 собрана `app-debug.apk` с `versionCode=2`.
- По отчёту предыдущего сборщика успешно выполнены 38 JVM-тестов и Android Lint без ошибок.
- APK установлена на реальный Android пользователем, подтверждён экран приложения и обновлённый набор правил.
- Код версии 0.1.1 был получен из исходного архива `KVN-Android-Starter-v0.1.1-test.zip`.

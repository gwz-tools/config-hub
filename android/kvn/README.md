# КВН — Конструктор Виртуальных Настроек (Android 0.1.3-test)

Рабочая Android-программа для подключения к VLESS/TLS или VLESS/Reality посредством
официального открытого движка **sing-box** (`libbox`) и платформенного **VpnService**.
Интерфейс: один главный переключатель VPN, отдельный экран настроек. Никаких готовых
учётных данных или приватных подписок в репозитории нет.

**Состояние проверки:** исходники 0.1.3-test подготовлены, однако реальная сборка и работа
туннеля **ещё не подтверждены**. До установки и проверки на Android нельзя считать этот
экземпляр работоспособным VPN. Последней действительно запущенной APK была 0.1.2-test
(без движка). Не выдавайте эту исходную версию за собранную APK.

## Подготовка и сборка

Требуются JDK 17, Android SDK Platform 35, Build Tools 35.0.0 и доступ к GitHub Releases.

```bash
python3 scripts/check_assets.py
python3 scripts/fetch_libbox.py
./gradlew --no-daemon --console=plain :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

Путь к APK: `app/build/outputs/apk/debug/app-debug.apk`. В GitHub Actions тестовый APK
размещается как артефакт запуска (не постоянный Release).

Из-за нативного движка размер APK увеличится на десятки мегабайт.
`libbox.aar` скачивается **не с непроверенного файлообменника**, а из публичного
релиза `singbox-android/libbox` 1.14.4, после чего строго проверяется SHA-256.
Это сторонняя сборка: см. `THIRD_PARTY_NOTICES.md`. Для публичного релиза рекомендуем
собирать libbox непосредственно из фиксированного исходника SagerNet и проверять исходники.

## Использование

1. Зайдите в «Настройки» (⚙), вставьте свою ссылку `vless://...`, нажмите «Сохранить профиль».
2. По умолчанию включена раздельная маршрутизация: DIRECT из проверенного набора
   направляется напрямую, PROXY и остальное — через VLESS. Выключение этого параметра
   отправляет весь трафик через VLESS.
3. Вернитесь на главный экран и нажмите большую кнопку «Включить».
4. Android покажет системный запрос разрешения на создание VPN. После разрешения
   приложение запускает реальный VpnService и нативный sing-box.
5. Кнопка «Выключить» закрывает native engine и TUN, уведомление VPN исчезает.

Поддерживаются VLESS/TLS/Reality c TCP (включая Vision), WebSocket и gRPC.
XHTTP и другие транспорты пока намеренно отклоняются с понятной ошибкой.
Ни один VLESS-сервер или UUID не встроен. Их нужно вводить **на устройстве**.
Ссылка хранится в SharedPreferences в AES-256-GCM, ключ — в Android Keystore,
не доступном для экспорта. Приватные данные никогда не отправляются в GitHub.

## Что ещё требует проверки

- Компиляция с зафиксированным `libbox.aar` 1.14.4 и Gradle 8.11.1.
- Реальная выдача разрешения Android VPN, создание TUN и завершение соединения.
- Работа VLESS Reality/Vision, DNS и IPv6 без утечек на Wi-Fi и мобильной сети.
- Фоновый режим на Samsung и восстановление после переподключения сети.
- Корректность разделения DIRECT / PROXY с реальными сайтами.
- Стабильная подпись APK перед обновлением поверх предыдущей установки.

## Архитектура и защита

- `MainActivity`: один переключатель и реальный статус из `VpnState`.
- `SettingsActivity`: импорт VLESS, выбор маршрутов, обновление правил и APK.
- `VlessProfile`: проверка VLESS-URI и формирование sing-box-конфигурации.
- `StoredProfile`: AES/GCM с ключом Android Keystore, данные только локально.
- `KvnVpnService`: foreground service, Android TUN, native libbox bridge, системное разрешение VPN.
- `PolicyStore`, `PolicyUpdater`, `PolicyValidator`, `PolicyRefreshWorker`: неизменная проверенная
  логика HTTPS/SHA-256/ETag/атомарного кеша/отката каждые 6 часов.
- `AppRelease`: отдельный пользовательский запрос обновления APK через проверенную страницу GitHub.

**Правила обновляются автоматически, но активная VPN-сессия использует тот снимок,
который был проверен на момент запуска.** Для применения новых правил нужен перезапуск VPN.

# КВН — Android

**Конструктор Виртуальных Настроек** — управление сетевыми профилями, маршрутами и подключениями.

Версия: `0.1.2-test`. Android applicationId: `ru.prostokvn.app`.

Это тестовая версия интерфейса и механизма обновления маршрутов. VPN-движок и VpnService пока отсутствуют: приложение не создаёт туннель и не защищает сетевой трафик.

## Сборка и проверки

Требуются JDK 17, Android SDK Platform 35 и Build Tools 35.0.0. Gradle Wrapper включён.

```sh
cd android/kvn
python3 scripts/check_assets.py
./gradlew --no-daemon --console=plain :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

В Windows используйте `gradlew.bat`. Результат: `app/build/outputs/apk/debug/app-debug.apk`.

Workflow `.github/workflows/kvn-android-ci.yml` выполняет проверку правил, сборку, JVM-тесты и Android Lint. Успешный запуск публикует APK и файл SHA-256 как GitHub Actions artifact; срок хранения — 30 дней.

## Обновления

Правила DIRECT/PROXY/BLOCK проверяются через GitHub каждые 6 часов при наличии сети, а при открытии — если срок последней успешной проверки истёк. Android может задерживать фоновые задачи. До активации проверяются SHA-256, размеры файлов, версия набора, структура и конфликты доменов. Используются локальный кеш и восстановление предыдущего рабочего набора.

Версия APK проверяется отдельно. Для более новой версии проверяется официальная HTTPS-страница релиза; она открывается только после подтверждения пользователя. Автоматической установки нет.

## Тестовая подпись

CI создаёт стандартный debug-сертификат в среде сборки. Он может отличаться от сертификата предыдущей установленной APK, поэтому установка поверх неё может быть невозможна. Это не релизный ключ. Пароли и ключи подписи в репозитории не хранятся.
